# AI Chat Exporter

A utility to export your AI conversations into beautifully formatted Markdown files. 100% private and runs entirely locally in your browser.

## Features
- **Browser Chats**: Export web-based conversations from ChatGPT, Claude.ai, and Google Gemini using a simple console script.
- **Claude Desktop App**: Upload and parse local `.jsonl` chat transcripts generated by the Claude MacOS Desktop App, with options to include Claude's internal thinking and tool executions.

## Setup
```sh
npm install
npm run dev
```

## Deployment
Deployed on GitHub Pages using Vite.
